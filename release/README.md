# قناة التحديث

لا يحتوي هذا المجلد بيان تحديث جاهزًا بقيم وهمية. شهادة توقيع ويندوز ورابط الموقع النهائي لم يتوفرا بعد.

بعد توقيع مثبّت حقيقي، استخدم `scripts/prepare-signed-feed.ps1`. يتحقق السكربت من توقيع ويندوز واسم المنتج ورقم الإصدار، ثم يكتب `signed-manifest.json` ويضبط الإعدادات. أعد البناء والنشر بعد رفع المثبّت الموقّع إلى GitHub Releases.

عند تفعيل القناة سيُنشأ `dist/updates/latest.json`، ويجب ربط File Orbit برابط HTTPS الثابت وبصمة شهادة الناشر قبل نشر البرنامج للجمهور. أدوات ذلك موجودة أيضًا في حزمة نشر البرنامج المنفصلة.
